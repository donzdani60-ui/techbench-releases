# TechBench — beta downloads

AI-assisted board repair workbench for phone/laptop technicians.

Grab the latest **Android APK** or **Windows zip** from the [Releases page](https://github.com/donzdani60-ui/techbench-releases/releases).

- **Android**: download the APK, allow 'install unknown apps', install.
- **Windows**: extract the whole zip, run techbench.exe (SmartScreen: More info → Run anyway).
